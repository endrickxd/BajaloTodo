## 2024-09-02 - Application-layer SSRF TOCTOU Limitation
**Vulnerability:** A Time-of-Check to Time-of-Use (TOCTOU) vulnerability where an attacker can exploit DNS rebinding to bypass application-layer SSRF validation (using `socket.getaddrinfo`) because the IP address could change between validation and the subsequent `requests.get()` fetch.
**Learning:** Application-layer IP validation is inherently limited by DNS rebinding attacks if the validation and the network fetch do not use the exact same IP resolution. The underlying IP may change between the validation step and the actual data retrieval by `requests` or other HTTP clients.
**Prevention:** To fully mitigate DNS rebinding in SSRF defenses, force the HTTP client to connect to the pre-validated IP address (and pass the original hostname via the `Host` header), or use a network-level proxy/firewall that strictly egress-filters internal IP ranges, abstracting the protection away from application-level DNS resolution limitations.
