## 2024-10-24 - [CRITICAL] Prevent SSRF when fetching external URLs parsed from API responses
**Vulnerability:** The application was vulnerable to Server-Side Request Forgery (SSRF) because it directly fetched a `download_url` returned from an external Cobalt API using `requests.get()` without validating the destination IP address. This allowed an attacker to control the Cobalt API response and trick the server into making requests to internal or restricted infrastructure.
**Learning:** When an application interacts with external APIs that return URLs (like tunnels or redirects) to be subsequently downloaded by the server, those URLs must be strictly validated. DNS resolution must be performed securely to extract the actual IP address being contacted, and this IP must be checked against private/local IP ranges. Furthermore, TOCTOU (Time-of-Check to Time-of-Use) issues, such as DNS rebinding, must be prevented by making the actual HTTP request using the validated IP address while explicitly setting the `Host` header to the original hostname. Additionally, `requests.get()` follows redirects by default, potentially bypassing initial URL validation; thus, manual redirect handling (`allow_redirects=False`) is required to validate each hop in a redirect chain securely.
**Prevention:**
1. Always validate external URLs before making HTTP requests.
2. Resolve the hostname to an IP address using `socket.getaddrinfo` (to support both IPv4 and IPv6, including IPv4-mapped addresses) and validate the resulting IP against private, loopback, link-local, multicast, and unspecified ranges using the `ipaddress` module.
3. Prevent TOCTOU/DNS rebinding by making the request directly to the validated IP address and setting the `Host` header.
4. Manually handle HTTP redirects (e.g., using a loop with `allow_redirects=False`) to ensure every URL in the redirect chain undergoes the same strict validation. Close intermediate responses to prevent resource leaks.
5. Provide explicit error messages or exceptions when a restricted IP is detected.
