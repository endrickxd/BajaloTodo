## 2024-10-25 - Prevent SSRF via URL bypass and TOCTOU
**Vulnerability:** Application allows arbitrary URLs extracted from `download_url` to be requested via `requests.get` without robust SSRF validation against loopback, link-local, private IP spaces, etc.
**Learning:** Checking a URL by parsing the hostname and verifying the IP addresses returned from `socket.getaddrinfo` avoids basic SSRF, but when doing `requests.get` afterwards, DNS can change (DNS rebinding / TOCTOU). A safer approach is to implement a custom `requests.adapters.HTTPAdapter` which subclasses `urllib3`'s `HTTPConnection` and `HTTPSConnection` and overrides `_new_conn()` to resolve and validate the IP before the socket connects. However, because requests handles redirects automatically by default (`allow_redirects=True`), custom HTTP session/adapters might be bypassed if redirects go to a different hostname, but wait - the session adapter applies to all subsequent requests including redirects!
**Prevention:** For streaming endpoints fetching user-provided/external-controlled URLs, implement a custom SafeAdapter that intercepts `_new_conn`, resolves the IP, strictly validates it against restricted ranges, and then connects to that explicit IP while preserving TLS/SNI. Use a `requests.Session()` with this adapter, or create a helper function like `safe_requests_get_stream` to encapsulate this. Or simply use `requests.get` with the custom session.
