## YYYY-MM-DD - Server-Side Request Forgery (SSRF) in Cobalt Downloader
**Vulnerability:** The `download_via_cobalt` function in `downloader/utils.py` blindly trusts the `url` returned by external Cobalt instances and calls `requests.get(download_url, ...)` directly on it. This enables a malicious Cobalt instance (or an attacker controlling the DNS of the URL returned) to perform Server-Side Request Forgery (SSRF), making the server send arbitrary GET requests to internal infrastructure (e.g., AWS Metadata endpoints at 169.254.169.254, or local services).
**Learning:** Always validate URLs parsed from external third-party API responses before issuing HTTP requests against them, even if the third party is expected to provide download links. Use application-layer IP validation handling custom DNS resolution to prevent bypasses like DNS rebinding.
**Prevention:** Implement an SSRF-safe request mechanism (e.g., a custom `requests` HTTP adapter) that explicitly blocks requests to private, loopback, and link-local IP addresses, and manually resolves hostnames to validate IPs before connecting.
