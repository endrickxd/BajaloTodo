## 2024-05-18 - [Fix Hardcoded Settings]\n**Vulnerability:** Django SECRET_KEY and DEBUG were hardcoded, potentially leading to secret leaks and production environments running with DEBUG=True.\n**Learning:** In local projects, it is easy to leave these hardcoded. Fixing this required using os.environ.get with a fallback to avoid breaking local dev.\n**Prevention:** Always use environment variables for sensitive or environment-specific configurations.
