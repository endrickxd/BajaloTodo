## 2024-10-04 - [SSRF via Unvalidated External Callback and Redirects]
**Vulnerability:** The application was vulnerable to SSRF because it used `requests.get()` to download media directly from arbitrary URLs returned by an external API (`Cobalt`), without resolving or validating the underlying IP addresses or preventing redirects to internal infrastructure.
**Learning:** External APIs can return malicious URLs (or configure URLs to redirect to local IPs) that force the application to interact with internal infrastructure, even if the initial request goes to a known external domain. Default `requests.get()` follows redirects automatically, bypassing initial URL checks.
**Prevention:** Always manually handle redirects using `allow_redirects=False` in `requests.get()`. For each hop, use `socket.getaddrinfo()` to resolve the hostname and validate that no resolved IPs fall into restricted ranges (private, loopback, link-local, multicast, or unspecified) using the `ipaddress` module before making the request. Explicitly close intermediate responses.
