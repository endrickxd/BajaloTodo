## 2025-02-27 - Hardcoded Secrets in Django Settings
**Vulnerability:** Django `SECRET_KEY`, `DEBUG`, and `ALLOWED_HOSTS` settings were hardcoded in `videodownloader_project/settings.py`. This exposes sensitive keys if the source code is compromised and improperly configures hosts/debugging in production environments.
**Learning:** Hardcoding sensitive settings directly in source code is a critical vulnerability as it exposes the secret key. If this key gets compromised, attackers could manipulate sessions or exploit other vulnerabilities. Additionally, having `DEBUG = True` and `ALLOWED_HOSTS = ['*']` hardcoded can lead to sensitive information disclosure and host header attacks in production.
**Prevention:** Use environment variables (e.g., `os.environ.get()`) to manage sensitive settings. This ensures secrets and environment-specific settings are not checked into version control and can be safely managed per environment (development, staging, production) while providing safe fallbacks for local development.
