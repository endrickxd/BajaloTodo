## 2024-05-18 - SSRF Vulnerability in Cobalt API Integration
**Vulnerability:** The application was vulnerable to SSRF in `downloader/utils.py` through the `download_via_cobalt` function, which fetches arbitrary URLs returned from external Cobalt instances directly via `requests.get()` without proper IP address validation. This could allow an attacker to bypass internal network restrictions or access sensitive internal services if a Cobalt instance is compromised or manipulated.
**Learning:** External API endpoints might return URLs that must be validated as they can be manipulated to initiate requests to internal services (DNS rebinding / IP-based SSRF). Standard validation using `socket.gethostbyname()` or similar is susceptible to TOCTOU (Time of Check to Time of Use) via DNS rebinding.
**Prevention:** Implement a custom `requests` HTTPAdapter overriding `urllib3`'s `_new_conn()` to resolve hostnames and directly create the connection, verifying that no resolved IP addresses belong to loopback, link-local, private, or unspecified ranges. This securely enforces application-layer validation and prevents DNS-based TOCTOU attacks. Always manually handle redirects (`allow_redirects=False`) within the application layer to validate each step in the chain.
