## 2026-07-27 - Secure Django settings\n**Vulnerability:** Hardcoded Django `SECRET_KEY`, `DEBUG`, and `ALLOWED_HOSTS` in settings.py.\n**Learning:** Hardcoding sensitive or environment-specific values in version control exposes secrets and can lead to unintended misconfigurations (like `DEBUG=True` in production).\n**Prevention:** Load these settings from environment variables using `os.environ.get()`, keeping the original hardcoded values as fallbacks to ensure local development environments do not break.
