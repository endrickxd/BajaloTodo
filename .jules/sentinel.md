## 2024-03-20 - Server-Side Request Forgery via External URL parsing
**Vulnerability:** The application fetches and directly streams URLs returned by the external Cobalt API using `requests.get()` in `downloader/utils.py`. This URL is not validated and can direct the backend server to fetch data from its own internal infrastructure, loopback addresses, or private AWS metadata services, resulting in a Server-Side Request Forgery (SSRF).
**Learning:** Default behavior of `requests` and Python standard library DNS resolution doesn't check whether resolved IPs fall into restricted ranges. Simple application-layer URL parsing validation is vulnerable to DNS Rebinding (TOCTOU). Securing requests requires completely overriding the HTTPConnection's `_new_conn()` socket creation step to use a pre-validated IP address directly.
**Prevention:** Always explicitly resolve hostnames via `socket.getaddrinfo`, validate the resulting IPs against private/restricted ranges using the `ipaddress` library, and then enforce that specific validated IP during socket creation. For `requests`, this involves creating a custom `HTTPAdapter` and `urllib3` connection classes. Never blindly trust URLs parsed from external APIs.
