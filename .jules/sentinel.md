## 2024-11-20 - SSRF Vulnerability in Fallback Video Downloader
**Vulnerability:** The application was vulnerable to Server-Side Request Forgery (SSRF) when using a fallback method to download media (Cobalt). The API returned a redirect or tunnel URL which was fetched using `requests.get()` without validating the destination host, potentially allowing requests to the internal network.
**Learning:** External APIs or fallbacks that instruct the application to download from an arbitrary URL must have the destination URL strictly validated. Because the underlying IP can change (DNS rebinding) and the `requests` library follows redirects by default, application-level IP validation using `socket.getaddrinfo` paired with manual redirect handling is required to securely process external URLs.
**Prevention:** Always validate external URLs using strict application-layer IP validation. Resolve hostnames to IPs and reject any that fall into private, loopback, or reserved ranges. Ensure that HTTP redirects are also validated by disabling automatic redirect following in HTTP libraries and checking each location header in the redirect chain.
