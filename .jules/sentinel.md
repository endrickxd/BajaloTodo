## 2024-10-19 - [SSRF vulnerability when handling external redirect URLs in Cobalt downloader]
**Vulnerability:** In `downloader/utils.py`, `download_url` parsed from external API responses was passed directly to `requests.get(download_url, stream=True)` without validation, allowing a malicious API to return internal/private IP addresses or trigger SSRF by DNS-rebinding redirects to local resources.
**Learning:** Default behavior of `requests.get` follows redirects and doesn't restrict destination IP space. An attacker controlling the download URL from the external cobalt-api source could make the backend scan internal IPs or access internal metadata services.
**Prevention:** Always use a helper function (like `safe_requests_get_stream`) that parses the destination URL, resolves its hostname using `socket.getaddrinfo`, and validates the final IP against private/loopback boundaries (using `ipaddress` mapped properties like `ipv4_mapped`). Handle redirects manually with `allow_redirects=False` to re-validate each hop.
