## 2024-10-23 - [Critical TOCTOU SSRF Vulnerability in Cobalt Fallback]
**Vulnerability:** The application fetches external URLs returned by Cobalt APIs (`download_url`) using `requests.get()` without any validation. This allows an attacker to exploit Cobalt to return a redirect or a direct URL pointing to internal network resources (SSRF), circumventing perimeter defenses. The vulnerability was found in `downloader/utils.py`.
**Learning:** We must not implicitly trust URLs returned by external services, especially those designed to act as intermediaries or proxies. Validating URLs by resolving their IP address before fetching is essential, but it is also important to remember that validating a hostname to an IP is susceptible to Time-of-Check to Time-of-Use (TOCTOU) DNS rebinding attacks. The underlying IP may change between validation and retrieval if `requests` resolves it again.
**Prevention:** Implement application-layer IP validation (e.g., using `socket.getaddrinfo` and `ipaddress`) for all external URLs before fetching them, ensuring requests are blocked if they point to private, loopback, link-local, multicast, or unspecified IP ranges. To mitigate DNS rebinding and handle redirects securely, use custom redirect handling (e.g., looping with `allow_redirects=False`) and validate the URL before each fetch. Be aware of IPv4-mapped IPv6 address bypasses.
