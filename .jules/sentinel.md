## 2024-10-23 - Application-Layer IP Validation for SSRF and TOCTOU DNS Rebinding Limitation
**Vulnerability:** The application utilizes external Cobalt API endpoints (`downloader/utils.py`) which return a `download_url`. This URL was being fetched with a standard `requests.get()` without validation, presenting an SSRF risk, as malicious servers could return URLs pointing to internal infrastructure.
**Learning:** When implementing SSRF protections through application-layer IP validation (using `socket.getaddrinfo` to check if IPs fall into private/loopback/link-local ranges), there's an inherent Time-of-Check to Time-of-Use (TOCTOU) DNS rebinding limitation. The underlying IP mapped to a domain may change between the validation check and the actual retrieval by the HTTP client.
**Prevention:** Always validate external URLs thoroughly before making requests, specifically extracting mapped IPv4 addresses correctly to avoid bypasses. Acknowledge and document the TOCTOU DNS rebinding limitation when relying on application-layer IP validation rather than a properly isolated or configured network layer.
