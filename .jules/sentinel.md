## 2024-11-20 - [Mitigating SSRF Time-of-Check to Time-of-Use (TOCTOU) DNS Rebinding Limitations]
**Vulnerability:** The application was vulnerable to Server-Side Request Forgery (SSRF) when downloading videos via external Cobalt API responses by directly requesting external, unvalidated URLs using `requests.get()`. This could allow requests to private, loopback, link-local, multicast, or unspecified IP ranges.
**Learning:** Application-layer IP validation via `socket.getaddrinfo()` to block restricted IP ranges mitigates many SSRF attacks. However, it introduces a Time-of-Check to Time-of-Use (TOCTOU) limitation due to DNS rebinding, as the IP associated with a hostname may change between validation and retrieval by the underlying library.
**Prevention:** We have implemented `is_safe_url` to perform the application-layer IP validation and `safe_requests_get` to explicitly handle redirects manually, checking the URL at every step. However, a deeper mitigation might require network-layer filtering, like network namespaces or egress proxies, to prevent TOCTOU DNS rebinding issues completely.
