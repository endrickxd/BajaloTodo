## 2024-09-26 - SSRF Vulnerability in External API URL Downloading
**Vulnerability:** Server-Side Request Forgery (SSRF) via unvalidated external download URL. The application queries an external API (Cobalt) to get a download URL, then downloads it locally using `requests.get(download_url)`. A malicious API response could provide an internal URL (e.g. `http://169.254.169.254/` or `http://127.0.0.1/`), causing the application to make internal requests and potentially exfiltrating sensitive data (e.g. cloud metadata).
**Learning:** Never blindly trust URLs returned from external, unauthenticated, or untrusted APIs. A seemingly external service could return URLs pointing to private/internal IPs, bypassing external firewalls. DNS-based bypasses are also possible where an external domain resolves to an internal IP.
**Prevention:** Implement strict IP validation using `socket.getaddrinfo` to resolve hostnames before making the HTTP request. Check that all resolved IPs are public and not private, loopback, link-local, or multicast.
