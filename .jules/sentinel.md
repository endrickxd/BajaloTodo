## 2024-09-14 - Securing Django Settings via Environment Variables
**Vulnerability:** Django settings like `SECRET_KEY`, `DEBUG`, and `ALLOWED_HOSTS` were hardcoded in `settings.py`. This is a critical security vulnerability as it can expose the secret key and potentially allow unauthorized access if committed to version control.
**Learning:** It is crucial to manage sensitive configuration using environment variables, especially for secret keys and debug settings. However, when migrating a codebase, it is important to retain the original hardcoded values as fallbacks in `os.environ.get()` to prevent breaking local development and testing environments that might not have these variables set up.
**Prevention:** Always use environment variables for sensitive settings in Django using `os.environ.get()`. Ensure that `import os` is present. During refactoring, use fallbacks carefully to maintain compatibility with existing local setups unless a strict environment enforcement policy is explicitly required.
